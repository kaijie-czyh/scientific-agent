# Scientific Agent

### 面向计算机与 AI 研究的科研协作工作台

从研究兴趣出发，将文献、问题、方案、结果与写作组织在同一个项目中。AI 协助检索、分析和整理，你掌握关键选择与研究判断。

[安装与配置](docs/getting-started.md) · [交给 Agent 安装](docs/getting-started.md#方式二交给编程-agent-安装) · [使用指南](docs/user-guide.md) · [反馈问题](https://github.com/weimeng09280929/scientific-agent/issues)

## 为什么做这个项目

论文读了不少，想法也记了很多，但“下一步做什么”“这个方案依据什么”“实验结果能支持什么”往往散落在不同工具和对话中。

Scientific Agent 以**研究项目，而不是一次问答**为中心，将这些内容连接起来：从选题到写作，持续保留研究依据、当前进展与后续任务。你可以暂停研究、完成外部实验，再回到同一项目继续。

## 核心能力

- **选题与文献调研**：结合实际检索到的论文探索方向，梳理已有方法、争议与研究缺口。
- **贯穿流程的科研指导**：在右侧对话框讨论当前问题，将合适的建议采纳到研究记录，随手保存灵感笔记。
- **方法与验证规划**：明确数据、对照、指标与实施步骤，将问题转化为可审核的研究方案。
- **结果整理与写作**：回填外部实验的实际结果，记录研究判断，整理提纲、稿件与可导出文档。
- **项目进度与延续**：保存项目材料、来源和修订记录，通过任务进度与人工确认节点推进研究。

## 一条可以反复修订的研究主线

```text
研究兴趣 → 文献与研究现状 → 研究问题 → 方法与方案
                                         ↓
成果整理与写作 ← 结果与研究判断 ← 外部实验与结果回填
```

不是一次点击后自动完成的直线流程。你可以根据新论文或实验结果回到前面的阶段，修改问题与方案，并复核受影响的记录。

**系统辅助规划和整理，实验由研究者在自己的环境中执行。** 任务保存后，无需一直开着网页等待实验完成。

## 使用案例：从联邦学习兴趣到研究记录

> “我想研究数据分布不一致对联邦学习的影响，但设备有限，希望先做一个小规模项目。”

1. **找依据**：检索相关论文，梳理方法与实验条件，在科研指导中讨论可行范围。
2. **定问题与方案**：收敛到特定数据和训练预算下的对比问题，明确对照、指标与验证步骤。
3. **执行与回填**：在自己的电脑或服务器完成实验，之后回到原项目登记实际结果与失败情况。
4. **整理成果**：根据证据记录支持、反驳或暂时无法判断的结论，再组织写作材料。

最终留下的不只是一段 AI 回答，而是一份可以继续修订的研究过程记录。[查看完整案例与操作](docs/user-guide.md#一个贯穿全流程的案例联邦学习研究)。

*以上是流程示例，不是已完成的实验或实测成果。*

## 我们的侧重点

Scientific Agent 不试图替代所有科研工具，而是做好它们之间的衔接。

| 使用需求 | 本项目的侧重点 |
| --- | --- |
| 不只问答，还要持续推进 | 把采纳后的讨论放入项目主线，明确当前问题、方案和下一步 |
| 不只找到论文，还要形成研究问题 | 将相关文献与研究现状衔接到方案、结果和写作 |
| 不只生成内容，还要区分证据 | 分开记录 AI 建议、计划、实际结果与研究判断，保留来源与版本 |
| 不必一次在线完成研究 | 支持暂停后继续，以及长周期外部实验后的结果回填 |

这些是定位差异，不是性能排名；其他工具也可能覆盖其中部分能力。

## 适合谁使用

面向课程研究、毕业设计、论文复现与小型科研项目中的学生、科研入门者和开发者。目前聚焦：

**AI 与机器学习 · 软件工程与计算机系统 · 计算机安全与隐私**

安全研究限于公开数据、模拟环境或明确授权的测试。暂不面向医学、临床或实物实验提供完整研究指导。

## 开始使用

- **自己搭建**：[安装环境、配置模型并启动工作台](docs/getting-started.md#方式一自己安装)
- **交给编程 Agent**：[复制安装指令](docs/getting-started.md#方式二交给编程-agent-安装)
- **已经启动**：[创建项目、推进研究与恢复进度](docs/user-guide.md)

底层通过 Agent Harness 组织模型路由、检索工具、分阶段任务、人工确认与过程保存。后端采用 Python / FastAPI，前端为原生 HTML / CSS / JavaScript，项目数据使用 SQLite 与本地目录保存。

> 当前为持续迭代的开发版本，建议先在本地单用户环境体验。检索和生成依赖配置的外部服务；系统不提供无人值守实验，不保证创新成立或论文可直接投稿。公网部署要求见[安装指南](docs/getting-started.md#数据保存更新与服务器运行)。
