## 本轮结论

本轮对仓库自动测试、补充验证脚本、浏览器交互、当前模型及外部文献源进行了测试，并修复发现的问题。保留现有导航、灵感笔记、人工确认和科研页面，不重新推翻界面结构。

五阶段流程已在隔离测试中贯通：文献检索与入库 → 研究思路 → 方法与人工审核 → 实验任务导出与结果回填 → 结果复核与稿件保存。外部搜索和模型在这一整链测试中使用明确标注的离线夹具；另有真实模型和真实文献接口连通性测试。两者不能等同于已经完成了一次真实科研实验。

系统当前交付的是实验任务说明，不承诺自动运行任意科研代码。用户需要实际执行实验、回填真实结果，审核后再进入写作。

## 已修复的问题

1. **中断恢复丢失材料。** 增加可序列化的流程上下文快照，保存领域、研究材料和阶段引用；恢复时重新注入客户端等依赖，不保存密钥。区分真实模式与 dry_run，防止测试材料被当成真实结果。人工审核处恢复不再重新生成前面的付费步骤。

2. **重复启动与人工意见未生效。** 启动前在锁内预留任务状态，避免并发启动；方法、实验方案、稿件收到修改意见后回到对应生成步骤并再次请求确认。真实模型失败、空输出和保存失败不会再被泛化模板或虚构产物编号掩盖。

3. **实验结果回填不可靠。** 整批校验后一次事务写入，拒绝错误状态、未知或重复任务、布尔值/字符串/非有限数值指标及越界的假设判断。运行中的项目不能同时回填。重复导出保持任务 ID，已完成结果不被重置；保存回填不自动启动下一轮模型调用。

4. **运行成功被误当成科研结论成立。** 完成一次任务不自动证明假设。保留全部关联证据和用户明确提交的判断；相反判断不会被直接标成支持。前端说明回填内容来自用户，不是独立核验。模型的建议不能覆盖确定性的待执行状态或放行写作。

5. **负结果无法正常形成报告。** 允许有真实指标但不支持假设的结果进入结果报告；仍拒绝未完成任务、缺失引用等情况。写作读取实际指标和说明，并要求披露证据限制，不能凭结果编号编造成效。

6. **文献冲突无法保存。** 移除不存在的清空接口调用，按内容标识幂等保存，兼容历史 UUID，保留人工裁决、创建时间和证据片段标识；不删除历史冲突。

7. **输出预算和检索上限失效。** 结构化请求及重试使用任务配置中的 max_tokens；为较长方法、实验配置等设置明确预算。真实请求发现 Sciverse 有时忽略服务端条数限制，现增加本地截断、零条请求短路和无效 JSON 容错。

8. **测试脚本误报及测试边界不清。** 更新过期接口、修正前端路径匹配、兼容 FastAPI 子路由展开，校验失败返回非零退出码；修复恢复检查中不存在的函数调用。dry_run 的占位论文引用检查不再冒充真实入库；材料发现 dry_run 不再请求外部数据库。总报告移除“冠军候选”等自动获奖评级。

## 仍需注意

- 第三方服务的限流、可用性和耗时不受本项目控制。此次 arXiv、Sciverse、Crossref 可用，不代表所有主题、所有时段均可用；S2、OpenAlex、OQMD 的异常仍需在产品中如实展示。
- 警告抽查包括 datetime.utcnow() 弃用和未识别的 pytest asyncio_mode 配置；未作为测试失败处理。后续应统一时区约定、清理测试配置，不能在未评估历史数据兼容性的情况下批量改时间格式。
- 单机线程运行不等于生产任务队列。上下文已持久化，但服务进程重启后并不承诺自动重启后台任务；当前应由用户明确恢复。
- 公网发布仍应单独验收登录与项目归属校验、用户数据隔离、调用额度与限流、HTTPS、密钥管理、备份恢复及运行监控。本轮没有进行公网部署、报名或支付接入，也不是上线安全认证。
- 自动测试不验证研究创新性、论文真实性的全部字段或实验结论的科学有效性；真实研究仍需人工审阅与实际实验。
