## 一、方向选择与科学问题理解

### 1.1 方向选择

选择方向三「材料科学文献驱动的科学发现智能体」，原因有二：

1. **问题真实性**：材料科学的知识高度沉淀于文献中——组分、结构、工艺与性能之间的关联大量以非结构化形式散落在数十年论文与专著里，人工阅读的覆盖能力与大模型时代的文献规模已形成根本性落差。这是一个真实且紧迫的科学问题。

2. **技术契合度**：我们已构建一个覆盖科研全生命周期（研究主题挖掘→文献查找→方法设计→实验设计→论文写作）的多 Agent 系统，其核心能力——文献检索与筛选、知识抽取、Research Gap 识别、结构化调研报告——正是本方向基本任务的要求。

### 1.2 科学问题理解

**核心科学问题**：如何构建一个能从大规模材料科学文献中自主阅读、推理并产出可验证科学发现的智能体系统？

具体拆解为三个子问题：

1. **知识抽取的结构化**：如何从非结构化论文文本中，准确抽取材料成分、晶体结构、性能指标、合成条件、模拟方法等结构化信息，并建立跨文献的实体链接？

2. **Research Gap 的可证伪识别**：如何不依赖人工预设，自动识别文献中未被充分探索的方向、矛盾结论或缺失的知识连接，且每个 Gap 都有清晰的文献证据链支撑？

3. **构效关系的可信发现**：如何让搜索算法（MCTS/贝叶斯优化/符号回归）与 LLM 深度融合——LLM 不只是生成搜索代码，而是参与搜索过程（生成候选假设作为种子、评估中间结果科学合理性、引导搜索空间剪枝），发掘具有新颖性和可信性的构效关系？

### 1.3 与已有工作的差异

当前主流材料科学 Agent（如 ChemCrow、LLM4Mat）多聚焦于「工具调用+实验执行」闭环，但在以下方面存在不足：

- **证据链可追溯性**：多数系统返回结论但不可回查到具体文献片段，难以区分「新知」与「已知」
- **Research Gap 识别**：多为事后总结，而非探索前定义的发现信号
- **搜索与 LLM 融合深度**：LLM 常仅生成搜索代码，未参与搜索过程的中间评估与剪枝

我们的系统通过**溯源链硬校验 + 原子概念分解 + Claim-Evidence 关联**三项设计应对上述不足。

## 二、技术方案

### 2.1 系统架构总览

系统采用 5 阶段生命周期设计，每个阶段由多个 Agent/Tool/Human 节点组成有向无环图：

```
research   →  ideation  →  design    →  experiment →  writing
(文献调研)     (思路生成)    (方法设计)    (实验验证)     (论文写作)
  10 节点        5 节点        6 节点        9 节点         7 节点
```

五阶段主流水线共 37 节点，加上路线 A 构效关系发现流水线（discovery，6 节点），
合计 **43 节点**（详见 `docs/node_architecture.md` 的完整节点清单与通信机制论证）。

**针对本方向，重点在 research 阶段（基本任务）+ design/experiment 阶段（路线 A 构效关系发现）。**

### 2.2 基本任务：文献调研 Agent（必做）

#### 2.2.1 文献检索与筛选

**多源融合检索**：集成三个数据源，互补覆盖：
- **arxiv API**：最新预印本（含 abstract 全文），适合抓前沿工作
- **Semantic Scholar API**：引用图谱/venue/影响力，适合评估论文重要性
- **Sciverse API**（赛题推荐）：465M knowledge records，证据片段级检索（非仅论文列表），每个结果含 doc_id + offset 可回读原文上下文

**子问题分解（借鉴 GPT-Researcher）**：把研究主题拆为 5-10 个子问题，每子问题独立检索，结果带 `source_subquery` 标记，便于后续交叉验证。

**相关性筛选（借鉴 PaperQA filter）**：LLM 对每篇候选打分（0~1），保留高相关性论文。含安全网机制：全被剔除时保留 top-3 避免下游饿死。

#### 2.2.2 知识抽取

论文入库时进行 chunk 化（按段落与 token 限制切分），每个 chunk 关联 paper_id。针对材料科学，抽取以下结构化实体：
- **材料成分**：化学式、元素组成、掺杂比例
- **晶体结构**：空间群、晶格参数、对称性
- **性能指标**：ZT 值、功率因子、热导率、电导率、Seebeck 系数
- **合成条件**：温度、压力、时间、前驱体、工艺步骤
- **模拟方法**：DFT、MD、蒙特卡洛、机器学习势函数

#### 2.2.3 Research Gap 识别

**交叉验证（借鉴 GPT-Researcher）**：对入库 chunk 做多源信息冲突检测与交叉验证，输出：
- `conflicts`：多方结论矛盾的陈述（含来源 paper_id/chunk_id + 立场 + 可信度）
- `consensus`：多方一致认同的陈述
- `gaps`：缺乏证据的子问题（即 Research Gap）
- `overall_confidence`：整体可信度评分

每个 Gap 都有清晰的文献证据链（关联到具体 paper_id），满足赛题「文献溯源完整性与可信度」要求。

#### 2.2.4 调研报告生成

基于 CrossValidate 报告 + 入库论文，生成结构化调研报告：
- **领域概览**：研究现状总结
- **Research Gap 清单**：每个 Gap 附证据链与可操作性评估
- **文献交叉引用**：论文间关系图谱（支持/反驳/补充）
- **冲突结论汇总**：矛盾发现及其可能原因

### 2.3 路线 A：构效关系发现

#### 2.3.1 搜索方法与 LLM 深度融合

**原子概念分解（借鉴 AI-Researcher）**：把构效关系拆为最小可独立验证的原子概念，每个概念同时给出数学公式（LaTeX）与代码实现骨架（Python stub），建立「公式↔代码」双向映射。

**LLM 参与搜索过程**：
- **种子生成**：LLM 从 Research Gap 出发，生成候选构效关系假设作为搜索种群种子
- **中间评估**：搜索过程中，LLM 评估中间结果的科学合理性（物理合法性、与已知文献的一致性）
- **空间剪枝**：LLM 引导搜索空间的剪枝与聚焦（排除物理不合理的区域）

**搜索算法**：采用贝叶斯优化 + MCTS 混合策略，在材料组分/结构空间中搜索最优构效关系。

#### 2.3.2 可信性与新颖性

- **证据链支撑**：每个发现的构效关系都关联文献证据（Claim-Evidence 链）
- **区分新知与已知**：与 Materials Project、OQMD 等公开数据库交叉验证
- **科学解释**：构效关系附带清晰的物理机制解释，而非黑箱输出

### 2.4 关键创新点

1. **溯源链硬校验**：所有科学发现（Claim）必须关联已验证的证据（Paper/Experiment），写作前强制校验，未通过一律拒绝——确保「结果可验证」
2. **原子概念分解**：方法拆为最小可独立验证概念，建立公式↔代码双向映射——确保「论文写一套、代码做一套」的痛点被根治
3. **实验失败自然停止**：实验未验证核心 Claim 时不强行写论文——符合科研伦理，避免「为写论文而写论文」
4. **多源证据片段级检索**：Sciverse 返回片段级证据（非仅论文列表），天然构成可审计证据链

### 2.5 工具与数据资源

| 资源 | 用途 | 接入方式 |
|------|------|---------|
| Sciverse API | 证据片段级文献检索（赛题推荐） | RESTful API / MCP |
| arxiv API | 最新预印本检索 | RESTful API |
| Semantic Scholar | 引用图谱/影响力 | RESTful API |
| Materials Project | 材料结构与性能数据库 | API（路线 A 交叉验证） |
| OQMD / NOMAD | 开放量子材料数据库 | API（路线 A 交叉验证） |
| MiniMax M3 | LLM（6亿+ token/月，1M 上下文） | OpenAI 兼容 API |

## 四、初步实验与可行性验证

### 4.1 已有系统基础

系统已完成端到端架构搭建与真实运行验证：

- **5 阶段 37 节点**（加 discovery 构效发现 6 节点共 43 节点）全部跑通（dry_run + 真实模式）
- **真实 LLM 调用**：MiniMax M3，研究主题「联邦学习公平激励机制」真实运行产出：
  - 36 篇 arxiv 论文抓取，6 篇入库
  - 5 个研究思路（基于 7 个 Research Gap + 8 处冲突 + 14 条共识）
  - 4 个思路通过验证，8 个 draft Claim
  - 7932 字符实验代码生成，3 个实验运行
- **前端 Web UI**：FastAPI + 单页应用，7 个页面，人工节点交互已验证

### 4.2 材料科学领域验证（进行中）

以「热电材料的构效关系与性能优化」为研究主题，验证系统在材料科学领域的文献调研能力：
- LLM 自动生成材料领域子问题（热电材料构效关系、文献挖掘方法、LLM4Mat、知识图谱、公开数据集等）
- arxiv 检索材料科学论文
- Research Gap 识别与证据链生成

### 4.3 可行性结论

系统架构已验证可行：
1. **领域适应性**：通过 topic 驱动，LLM 自动生成领域特定子问题，无需硬编码领域知识
2. **多源检索**：arxiv + S2 + Sciverse 三源融合，Sciverse 无 token 时优雅降级
3. **证据链**：CrossValidate 产出含 paper_id/chunk_id 的证据链，满足溯源要求
4. **可复现性**：dry_run 模式可无 API 验证架构，真实模式可复现完整流程
