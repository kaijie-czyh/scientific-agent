# 使用指南

[项目首页](../README.md) · [安装与配置](getting-started.md) · [当前版本](current-status.md)

## 五分钟认识工作台

1. 点击 **新研究**，直接说明兴趣、已有方向或问题，也可先选择 PDF / TXT / MD。首次发送才创建项目；领域未确定时先确认领域，不需要填写长表单。
2. 在中央对话讨论，选择“带我入门”或“直接处理问题”。已知条件可以直接说明，未知设备、预算和期限保留待确认。
3. 准备好后，明确选择选题探索、检索／阅读或研究现状整理等任务。检索会调用实际来源并将资料保存到文献库；单纯打开页面不启动任务。
4. 打开 **研究材料** 查看文献、现状报告与候选问题。核对来源与实际阅读范围后，明确 **采用这个问题**，使其成为正式研究问题。
5. 围绕已确认问题请求方案。先看摘要，再打开完整草案审阅；需要时修改条件、讨论某一部分或请求修订。最后明确采纳，从顶部 **下载当前产物** 下载相应版本。

流程止于方案。没有实际实验结果时，不会将其补写为已验证结论，也不进入论文生成。

## 新研究、项目与对话怎样区分

- **新研究**：独立研究主题，不携带原项目归属。输入、选文件或点击开场选项都不会提前创建空项目。
- **在本项目新建对话**：属于当前项目，共享正式材料，聊天历史独立。适合另开一段文献比较、问题细化或方案讨论。
- **最近对话**：回到准确的项目和会话。
- **项目**：查看项目与已有会话，不会因打开项目自动创建新会话。

正式问题、方案与文献归项目；临时讨论归会话。未采纳的想法不会自动变成其他对话的正式依据。

## 怎样从论文走到方案

### 明确条件

说明自己想回答的问题，以及已知的时间、设备、数据与经验。不确定就直接说“不确定”。聊天中提到的新条件不等于已保存的正式项目条件，修改时请核对材料中的记录。

### 检索和阅读

可以导入已有材料，也可以明确发起有界检索。任务卡显示真实状态：运行中、完成、部分完成、失败或中断；展开 **查看检索审计** 可核对查询、来源、筛选和错误。

文献页也展示对话任务审计。返回、候选、纳入整理、筛选排除、新入库和关联已有各有含义，不能简单相加为文献总数。失败来源不表示“这个主题没有论文”。

材料卡标记实际可用范围：只有元信息、摘要或正文片段。入库不代表已经下载或读完全文；原文下载取决于可访问性与权限。

### 了解现状并确认问题

基于已有材料，讨论不同工作解决什么、条件有何差别、哪些局限有明确依据。research gap 是需要核实的研究切入线索，不是自动证明的创新点。

查看候选、继续讨论和正式采纳是不同操作。有多个问题时，明确选择本次方案对应的问题，避免混用依据。

### 生成、审阅与修改

方案分为计算研究、理论研究、实验研究设计三类。生成前应有明确选择的研究问题；缺少依据时只能按实际范围呈现讨论稿。

生成结果先是草案。可以要求缩小范围、调整比较或论证设计，再审阅新版本。旧版本保留；依据变化的草案会提示复核，不能偷偷更新版本后直接采纳。文本“就采用这个方案”不等于已经保存成功，应使用具体采纳操作并核对结果。

**方案可审阅**表示问题、方案及其依赖符合当前流程要求，不表示科学上正确、创新成立或结论得到验证。

打开方案后，**交付检查**优先展示待核对项；展开研究条件可查看实际值及其依据。“逐条核对引用片段”显示对应陈述、来源及实际位置；摘要不视为全文，没有页码时不会补造页码。点击“讨论这一项”“讨论这条依据”或“讨论比较条件”只准备可编辑的讨论请求，发送前不调用模型、不改写或采纳方案。已有输入会先征求是否保留并追加，取消后仍停留在阅读位置。

材料研究方案还可展开 **材料数值与比较条件**，查看当前可匹配引文中的数值、单位、温度、样品与测量条件词、实验或计算用语。它们是原文线索，不是已经关联好的完整测量记录；缺少线索不等于论文缺失数据，也不证明研究空白。比较前仍需核对性质定义、成分、晶相、制备和测量方法及误差，不自动换算、排序或把计算值当作实测值。

检查发现缺项时，仍可保留、讨论和下载草案；请先补充资料或核对条件，再按原有流程修订。方案下载附带同一套交付检查，正文和历史版本不因此被重写。引文匹配只表示片段可找到，仍需研究者判断是否支持陈述、比较是否公平、方案是否可行。

点击 **重新核对** 可重读当前资料；失败时会保留上次报告并提示它不是本次成功检查的结果。

纯讨论请求会明确保留“本次不生成或修订方案”的约束，避免旧草稿中的生成要求被误执行。若要切回生成，请先修改相互矛盾的草稿，再准备方案请求。已准备方案时，关联问题必须明确有效；推荐回复不会偷偷沿用未发送的方案请求。准备检索依据前请先整理已有草稿，避免把多段要求混成检索主题。

## 在哪里找材料和下载

- 左侧 **文献与资料**：导入、搜索、浏览论文和检索审计。
- 左侧 **研究方案**：当前正式方案、待采纳草案与历史版本。
- 对话顶部 **研究材料**：统一阅读面板，查看研究概况、文献／报告与方案；窄屏可关闭返回对话。
- 对话顶部 **下载当前产物**：当前项目的真实产物目录，包含名称、版本及草案／待复核／历史标记。
- **笔记**：记录临时思路。Ctrl / Cmd + Enter 保存；未保存草稿按项目隔离，不会自动成为研究条件。
- **更多**：任务活动、研究指南、待确认事项及历史材料。

Markdown 为主要可导出形式，具体可用格式以条目显示为准。公式使用文档阅读组件渲染；HTML／打印能力与原有 Word/PDF 导出的格式支持不同，不能假定所有格式完全一致。

PDF 保留完整引文、条件、代码及表格内容；当前 Windows 字体回退已验证科学上标、下标和负号。若表格单行超过一页高度，会明确提示改用 Markdown 或 DOCX，不用截断后的内容替代原文。其他系统的字体环境仍需单独核对。

方案与材料的阅读版导出显示论文编号、题名和 DOI，版本与未验证标记仍保留；自动附加的数据库 ID、指纹和程序字段不作为正文。需要保留原始标识供程序处理时，可导出项目 JSON。系统不会为了去除标识而盲目改写自定义历史原文。

引用检查优先显示资料原有的阅读范围，例如摘要、出版方目录简介或上传文本节选；“已存片段”和页码只描述匹配位置，不表示已经读完全文。

## 先体验教学案例

从首页 **案例体验** 选择联邦学习或硫化物固态电解质案例。标准路径读取预先核验的资料，不实时检索、不下载外部材料、不调用模型。

主要体验：明确教学条件 → 查看文献 → 比较候选并明确采用问题 → 审阅、修改、采纳并下载方案。案例说明、教学设定和未验证事项会保留在产物中。

未覆盖的自由问题不会偷偷交给模型。选择 **带着这个思路开始自己的研究** 时，会创建独立普通项目；公开资料和草案作为有来源的参考，教学条件不会自动成为你的真实条件，问题和方案也不会自动确认。

## 失败、刷新与继续工作

- **不知道模型是否配置**：展开输入区的运行配置，区分规则指导、配置缺失和已配置但未验证连接。重新读取配置不请求模型，也不测试余额。只有模型模式下全部主功能均缺配置时，页面才阻止无效生成；部分功能缺配置仍可尝试已配置功能。离线教学不依赖模型配置。
- **回复较慢**：查看对应消息的处理状态。页面可切换，刷新不等于取消，也不会自动重发模型请求。
- **超时或响应丢失**：先核对原请求状态，再主动重试。用户消息与已保存材料保留，不要反复新建项目。
- **上传未确认**：使用“核对上次上传”，同一请求不会重复建立文献。浏览器刷新无法保留本地 File，看到提醒后需重新选择原文件；不要忽略附件提示直接当作已上传。
- **部分来源失败**：已有资料保留；根据任务提示等待限流或补跑失败来源，不把失败当作无结果。
- **草案过期**：保留查看，核对变更的条件、问题或来源后重新讨论／修订；不通过改前端版本号绕过复核。
- **找不到项目数据**：确认启动的数据目录。数据库缺失不会被替换为空白项目，不要删除旧目录“修复”。
- **旧实验和稿件**：通过历史材料查看或导出，不允许借旧入口继续执行实验、生成结果或论文。

模型回复和方案必须核对。本地软件测试不能替代真实模型质量、科研正确性或导师审阅。
