# 首版领域收敛

本次只收敛产品范围，不重做页面，不新增实验执行能力，不修改写作流程。

## 开放范围

- `computer_science`：软件工程与计算机系统，关注软件任务、负载、可靠性与性能。
- `ai`：AI 与机器学习，关注模型、算法、RAG、Agent、复现与评测。
- `security`：计算机安全与隐私，关注威胁模型、防护效果及代价，仅限公开数据、模拟环境或明确授权的测试。

新建项目去掉医学、生物、材料、化学、物理、能源与任意自定义领域入口。保留自由填写具体研究兴趣，但不再声称任意学科可用。未传领域的旧客户端默认进入计算机系统方向，不自动推断医学等学科。

## 能力边界与历史兼容

系统辅助检索、讨论方法、规划任务与整理用户提交结果，不代跑实验、不审定创新。暂不提供医学、临床、药物、湿实验、实物设备操作指导，以及真人访谈或人体实验的完整指导与伦理审定。

旧领域画像与数据不删除、不迁移、不重命名。历史项目的文献、笔记、对话、研究记录与导出保留；新启动科研流程、方向推荐、方法重生成及科研指导会在入口检查领域。已运行的线程不会被本次修改主动中止。历史项目不能通过方向推荐接口静默换领域。

领域白名单不是高风险主题语义分类器；仅把医学主题填在 AI 名下并不会被当前白名单可靠识别。界面及指导提示明确限制范围；更完整的主题识别、澄清确认与审核机制留待后续建设，不能宣传为已有安全保障。

## 尚未建设

研究类型的用户确认、按类型细化研究现状与评测清单、长期待办恢复、范例体验入口以及写作衔接修复不在本次改动范围。后台代码更新需重启服务生效；静态页面刷新即可读取新入口。
