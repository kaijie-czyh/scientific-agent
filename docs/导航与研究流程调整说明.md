# 导航与研究流程调整说明

2026-10-16。本轮在原界面上增量整合，不另建一套产品，也不删除旧研究数据。

## 当前导航

- 项目：项目总览、新建与管理。
- 研究过程：选题探索、文献库、研究现状、研究问题、方案与实验、成果写作。
- 任务与记录：任务进度、灵感笔记、待确认事项。
- 使用指南：研究指南。

名称、快捷键、页面标题、旧链接归属和右侧指导上下文共用 `web/static/research-navigation.js`。后端阶段名称与 API 路径不改，避免破坏已有项目。

## 合并与保留

原“研究缺口”扩展为“研究问题”，含“我的研究问题”“文献中的待核实问题”“论断与证据”三个子页。Claim 不再占用独立菜单，但原数据、引用跳转、筛选与 `page=claims` 深链仍可用。

原“调研报告”改为“研究现状”：保留共识、冲突和文献疑问，强调其覆盖范围仅限已检索材料，不宣称没有人做过类似研究。

原“实验”扩展为“方案与实验”：保留方法文档、任务书和旧实验记录，新增保存研究方案、实际结果与用户判断的入口。方案必须关联研究问题，结果必须关联方案；已完成的计算实验需要实际指标，运行失败不能当作反驳假设的证据。

新增“成果写作”：保存写作提纲，查看原流程已经保存的最新稿件和修改意见，导出研究记录。没有正文时如实提示，不生成占位稿件。提纲不会自动覆盖原稿件，完整写作自动化仍复用原流程，不宣称已经全部迁入新记录链路。

阅读和写作方法论合并到“研究指南”两个标签中，原内容和历史深链保留。灵感笔记、顶部流程条、待确认功能和已有下载接口保留。

## 记录与事实边界

对话、待采纳建议、正式记录分别保存。新记录和原知识库使用同一个项目，不把旧 VERIFIED 状态迁移成独立科学核验。原项目数据未删除，也不启动模型、检索或实验来填满空页面。

新稿件浏览接口只读取当前项目产物目录内的 Markdown/文本文件，限制单份预览长度；越界文件路径不读取。下载仍复用已有接口，本轮没有全面改造旧下载安全逻辑。

## 验证

41 项回归测试通过，覆盖工作记录、人工采纳、版本冲突、结果边界、原笔记、论文功能、导航定义和产物浏览。

无界面浏览器验证 12 个菜单、3 个旧链接、问题/方案/提纲保存及刷新恢复、Markdown 导出、页内标签、指导上下文、输入问号和 375px 窄屏。记录仅写入标注为演练的项目；未调用模型，未运行实验。演练记录不作为科研证据。

同时修复：空 CSS 状态类导致已创建项目误显示“运行中”；异步状态响应跨项目污染；研究问题角标未统计新保存问题。

预览：`docs/research-navigation-preview.png`。

## 后续范围

这次完成入口与记录骨架。下一步应逐模块核查真实检索质量、研究问题生成与方案验证，再整合自动写作；不能把导航联调通过等同于真实科研全流程已经验证。
