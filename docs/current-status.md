# 当前版本说明

[项目首页](../README.md) · [安装与配置](getting-started.md) · [使用指南](user-guide.md)

## 产品定位

面向计算机与 AI 研究的人机协作工作台。通过文献、问题、方案、结果、研究判断与写作记录组织持续研究；AI 负责辅助，用户保留关键选择。

## 当前工作版本包含什么

- 选题探索、文献检索与阅读辅助、研究现状整理。
- 结合项目与所选材料的科研指导，建议经过用户采纳后形成研究记录。
- 项目目标、研究问题、方法方案、结果与判断的关联管理。
- 既有材料利用、项目继续入口、修订留痕与下游复核提示。
- 外部实验任务规划、实际结果登记与成果整理。
- 方法文档与研究记录的本地公式预览、原文切换、离线 HTML 下载和公式版打印/PDF。

本轮将新增功能代码、必要静态资源与对应回归测试一并同步。该工作版本仍不是完成公网验收的正式发行版；实际代码以 GitHub 对应提交为准。私人项目、论文、密钥与运行日志不随源码发布。

## 使用时应了解的边界

| 项目 | 当前边界 |
| --- | --- |
| 检索与阅读 | 依赖外部来源、网络及授权；取得元数据不等于已经下载或读完全文 |
| 科研指导 | 依据提供的材料与模型进行辅助，不能保证新颖性、正确性或可行性 |
| 实验 | 主流程以规划、外部执行和回填为主；不提供已完成安全验收的无人值守实验 |
| 结果与判断 | 用户提交的数字不会因此获得独立复现认证；失败、反驳与无法定论需要区分 |
| 写作 | 可整理骨架和稿件；缺失证据不能以预期数字代替，不保证投稿就绪 |
| 恢复 | 项目资料持久保存；服务中断后的外部请求与人工等待需要检查并恢复 |
| 部署 | 建议本地单用户或受控试用；多用户隔离、限流与公网安全尚需完善 |

## 运行与验证

安装和自查步骤见[安装指南](getting-started.md#安装后自查)。自动化回归与真实模型调用、实际检索、完整用户流程分别验证，不能相互替代。本次同步主要通过离线夹具检查研究主线、恢复、项目归档、材料关联、下载与公式格式，不运行真实科研实验；Word/PDF 原下载仍是简化文本版，完整公式 PDF 请使用方法文档中的打印入口。

后续正式发布时，应随代码同步更新本说明，并明确对应提交及验证范围，不使用旧报告代表当前状态。
