# 当前版本与使用边界

[项目首页](../README.md) · [安装与配置](getting-started.md) · [使用指南](user-guide.md)

## 当前产品

Scientific Agent 是理工科科研方案工作台：

**明确目标与条件 → 了解研究现状 → 确认研究问题 → 形成并审阅方案。**

产品入口最多推进到 DESIGN。历史执行阶段不伪装成新产品进度；已有实验、结果和稿件仍可查看与导出，但不新增结果、研究判断、写作骨架或实验／论文执行。

## 已有能力

- 原生前端中央科研对话、项目导航、材料阅读与真实产物下载。
- 项目内多会话：共享正式材料，隔离聊天历史。
- 新手／直接指导方式、讨论选项与经过服务端绑定的明确操作。
- 有界文献检索、导入、研究现状整理与来源审计；区分成功无结果、来源失败、筛选排除和部分完成。
- 从兴趣、阅读、研究缺口到候选问题、方案的阶段引导；不强制所有用户从零开始。
- 计算研究、理论研究、实验研究设计三种方案，支持草案、修订、明确采纳及版本导出。
- 方案交付检查：页面与导出共用只读检查，列出引用片段位置、资料变更和待确认条件；不提供科学有效性评分。
- 材料方案审阅：从匹配引文摘取数值、单位、温度、样品与测量条件词、实验或计算线索；仅供人工核对，不自动换算或排名。
- 运行配置引导：只读检查主流程任务路由与凭据是否存在，区分规则模式、配置缺失和连接未验证；提供离线教学入口。
- 方案待核对项、条件实际值、逐项讨论与显式刷新；保留已有输入，检查失败保留上一份报告。
- 纯讨论与生成意图分开，已准备的方案必须明确关联有效问题；推荐回复不继承未发送的生成请求，重新展开审阅时重读检查。
- PDF 保留完整长引文、条件与代码，Windows 科学字形回退保留单位上标／下标；超高表格明确提示改用 MD／DOCX。
- 阅读检查优先保留资料声明的实际阅读范围，目录简介不按摘要或全文处理；已存片段与实际页码分开说明。
- 面向研究者的方案与材料导出使用参考编号、论文题名和 DOI；自动附加的内部 ID、指纹与程序状态字段不进入正文。项目 JSON 与原始记录保留追溯信息，自定义历史原文不作盲目替换。
- 两个预置离线教学案例，采用版本绑定与独立学习进度。
- 用户消息先保存、请求状态查询、显式重试、上传幂等、笔记草稿隔离及迟到响应保护。
- 检索模型异常使用安全类别与行动提示；历史诊断原文在任务接口读取时隐藏，不改写历史数据库。
- 补跑以排队归属和事务内尝试版本防止重复领取；后台启动失败明确落为失败，重启遗留排队可主动恢复。
- 问题、条件、引用或正文片段变化后复核依赖材料；读取项目不自动建库或迁移历史数据。

九类开放方向以 core/research_scope.py 为准：计算机系统与软件工程、AI、安全与隐私、工程、材料、物理、化学、能源、数学。开放领域表示支持研究规划，不代表拥有该领域实验执行或专业审核能力。

## 验证应怎样理解

离线 API／SQLite 测试、实际主应用浏览器检查与真实模型／来源验证分别进行，不相互替代。

近期使用临时项目验证了会话与材料隔离、方案阶段边界、上传和笔记保护、导航计数以及审计展示，检查了桌面与 390px 窄屏。测试数量只对应具体工作区和用例，不是整个产品的无缺陷保证。

一个公开联邦学习真实体验样例曾完成检索入库、问题确认、方案生成、采纳与导出；同次体验也出现网关连接失败，方案修订未成功。因此不能宣称所有真实路由、所有研究方法的回答质量或端到端稳定性均已通过。

源码发布不包含该样例的个人项目数据库、真实请求正文、调用日志或密钥，也不要求使用者采用某一家网关。

## 已知限制

| 内容 | 边界 |
| --- | --- |
| 研究依据 | 元信息、摘要不等于全文；缺口不保证创新，完整方案不保证科学有效 |
| 真实调用 | 依赖模型、网关、网络与额度；可能耗时或失败，重试仍可能产生额外外部费用 |
| 阅读与下载 | 不保证所有 PDF 可获取或可解析；扫描件可能需要额外 OCR |
| 导出 | 具体格式以条目支持为准；Word/PDF 原导出仍有排版限制，公式优先使用现有渲染／打印路径 |
| 教学 | 标准路径离线可用；预置内容不是最新实时调研，教学完成不等于结论验证 |
| 恢复 | 保存状态可以查询与恢复；中断后由用户核对并主动重试，不保证外部模型仅调用一次 |
| 服务进程 | 本地单用户、单 worker；不具备生产级分布式任务编排 |
| 公网 | 账号、项目权限、多租户、限流、部署和安全交付不在本版完成范围 |

暂不支持临床、人体、药物、湿实验、危险操作或实物设备操作指导。真实研究仍需核对来源、可行性与专业审核事项。

## 发布内容

保留运行代码、静态组件及许可证、教学数据包、回归测试、安装与使用文档。教学旧包属于已有体验的版本兼容依赖，不等同于无关历史材料；正式版本不能在用户体验中途被替换。

本地密钥、项目数据库、私人文件、调试日志、内部审查截图和临时报告不属于源码发行内容。当前适合本地体验，不代表已经具备公网发布条件。
